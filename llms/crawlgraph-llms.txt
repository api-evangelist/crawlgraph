# CrawlGraph

> Free backlink intelligence powered by Common Crawl's hyperlink graph (121.1M domains, 3.90B links). Paste any domain, see every site linking to it. No signup. $99 lifetime, unlimited queries.

CrawlGraph is a backlink-checker SaaS for SEOs, indie founders, and researchers priced out of Ahrefs and Moz. The hyperlink graph from Common Crawl's quarterly web crawl is reindexed within days of each release; data spans 2017 through the latest 2026 release.

## Core pages

- [Homepage](https://crawlgraph.com): product overview, free preview, pricing.
- [Gap analysis](https://crawlgraph.com/gap-analysis): compare your backlinks against up to 4 competitors.
- [API documentation](https://crawlgraph.com/docs/api): public REST API with a FREE tier (15 backlink calls/month, self-serve key by email, no card). The $99 lifetime license raises this to 1,000 backlink lookups + 50 gap analyses per month and unlocks the gap and outreach tools in the API and MCP server.
- [Blog](https://crawlgraph.com/blog): articles on backlink methodology, Common Crawl, comparisons with Ahrefs and Semrush.
- [MCP server](https://github.com/pucilpet/crawlgraph-mcp): "crawlgraph-mcp" on npm (npx -y crawlgraph-mcp). Four tools for backlinks, gap analysis, outreach targets, and releases, usable from Claude, Cursor, and Cline.

## Pricing

- Free: 5 referring domains shown per query, no signup.
- Lifetime: $99 once, unlimited queries, full results, CSV/JSON export, gap analysis.
- SEO Fix addon: $5/month, optional. One AI-generated high-impact fix emailed monthly.

## Data source

Common Crawl hyperlink graph - open dataset published quarterly at https://commoncrawl.org/web-graphs. CrawlGraph imports the vertices (~850 MB) and edges (~16 GB) files, queries them via DuckDB, caches per-domain results in SQLite for 30 days.
